# 🎉 Formulário de Convite

Uma aplicação web moderna para criação e personalização de convites digitais, desenvolvida com React e Tailwind CSS.

## 📋 Sobre o Projeto

O Formulário de Convite permite que usuários criem convites personalizados para eventos de forma simples e intuitiva. A interface foi projetada para oferecer uma ótima experiência de uso, com opções de customização visual e preenchimento de informações do evento.

## ✨ Funcionalidades

- ✅ Cadastro do título do evento
- ✅ Seleção de data e horário
- ✅ Escolha entre evento presencial ou online
- ✅ Definição do local do evento
- ✅ Descrição personalizada
- ✅ Seleção de tema visual
- ✅ Escolha de cores para o convite
- ✅ Alternância entre modo claro e escuro
- ✅ Upload de imagem de capa
- ✅ Informações de contato do organizador
- ✅ Validação dos campos do formulário

## ⚙️ Como Executar o Projeto

### Clone o repositório

```bash
git clone https://github.com/dodogm/Formulario-de-convite.git
```

### Acesse a pasta do projeto

```bash
cd Formulario-de-convite
```

### Instale as dependências

```bash
npm install
```

### Execute o projeto

```bash
npm run dev
```

Após iniciar o servidor, acesse a URL exibida no terminal, normalmente:

```text
http://localhost:5173
```
